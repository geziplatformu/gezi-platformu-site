# Gezi Platformu Web Sitesi

Bu site statik HTML/CSS/JS yapısında hazırlanmıştır ve Vercel, Netlify, GitHub Pages veya herhangi bir klasik hosting üzerinde yayınlanabilir.

## Tur bilgilerini değiştirme

Tüm tur bilgileri `tours.js` dosyasındadır. Fiyat, tarih, rota, görsel, açıklama gibi alanlar tek yerden düzenlenebilir.

## Yerel önizleme

Klasörü bir statik sunucuda açın. Örneğin:

```bash
python -m http.server 8000
```

Ardından tarayıcıda `http://localhost:8000` adresini açın.
